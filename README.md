# 【アプリ名】
忘れ物管理アプリ

## 誰の、どんな困りごとか
我々は学内の忘れ物の情報を一元化できていない点に着目した。
学内で忘れ物をしたとき、生徒はどこに問い合わせたらいいのだろうか？　　
結論忘れ物は校門を入ってすぐ左の守衛室に集められていることが多い。だが一方で貴重品は教務センターで保管されるなど例外もある。このように学内で忘れ物をしたとき、生徒はいちいち守衛室や教務センターへあるかもわからない忘れ物を探しに行く必要がある。また守衛室や教務センターは忘れ物がきたとき、拾った場所などの情報を小さいメモに書いてそれをはりつけて忘れ物ボックスにいれて保管しているだけである。そのため実際に生徒が忘れ物を訪ねてきたとき、ボックスの中からあるかもわからない忘れ物を探す必要があるに加えて、ない場合はほかの管理している場所に電話で確認する必要がある。我々は忘れ物情報を一元化してどこになにがあるかをすぐ確認できるようなwebアプリを作り、このような煩雑な業務を楽にできないかと考えた。


## コア機能1つ
忘れ物をweb上で管理してばらばらで体系化されていない情報の一元化を図り、業務量の軽減を目指す。
忘れ物がきたらどこにあったかなどの情報と写真をとってアプリに入力するだけでアプリ上で忘れ物の有無を管理することができる。また生徒は忘れ物をしたと気づいたときそのwebアプリをみることで、自分の忘れ物が届けられているか、またどこに届けられているかがすぐわかることができる。


## 誰が・いくら・なぜ払うか
守衛室、教務センター生活課の業務軽減が見込まれるため同志社大学側と交渉することができる。
